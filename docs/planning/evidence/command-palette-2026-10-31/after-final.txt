           │  ❯ Busca una acción o escribe un comando…                                                                                        │
           │  ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────  │
           │  ─ Reproducción ───────────────────────────────────────────────────────────────────────────────────────────────────────────────  │
           │    play [<consulta>...]  reanuda; con consultas busca y reproduce                                                                │
           │    select                elige una canción con búsqueda fuzzy y reprodúcela                                                      │
           │    pause                 pausa la reproducción                                                                                   │
           │    toggle                alterna play/pausa                                                                                      │
           │    stop                  detiene la reproducción                                                                                 │
           │    next                  pista siguiente                                                                                         │
           │    prev                  pista anterior                                                                                          │
           │    seek <+N|-N|mm:ss>    cambia la posición                                                                                      │
           │    vol <0-100|+N|-N>     fija o ajusta el volumen                                                                                │
           │    shuffle [on|off]      alterna o fija shuffle                                                                                  │
           │    repeat [off|all|one]  alterna o fija el modo repeat                                                                           │
           │    status                muestra el estado actual                                                                                │
           │  ─ Cola ───────────────────────────────────────────────────────────────────────────────────────────────────────────────────────  │
           │    add <consulta|ruta>...       agrega a la cola (consultas o rutas)                                                             │
           │    playnext <consulta|ruta>...  reproducir después, en orden, sin interrumpir la pista actual                                    │
           │    queue                        muestra la cola                                                                                  │
           │    jump <pos>                   salta a una posición de la cola                                                                  │
           │    move <de> <a>                mueve una pista de la cola a otra posición                                                       │
           │    remove <pos>                 quita una pista de la cola                                                                       │
           │    undo                         deshacer la última eliminación de cola sin reiniciar audio                                       │
           │    clear                        vacía la cola                                                                                    │
           │  ─ Biblioteca ─────────────────────────────────────────────────────────────────────────────────────────────────────────────────  │
           │    scan [<ruta>]      (re)escanea la biblioteca                                                                                  │
           │    rescan [<ruta>]    (re)escanea la biblioteca                                                                                  │
           │    search <consulta>  busca por título/artista/álbum                                                                             │
           │  ─ Playlists ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────  │
           │    playlist <sub> [args]                 gestiona playlists (list|show|create|delete|add|remove|play|save|export|import)         │
           │    playlist list                         lista las playlists                                                                     │
           │    playlist show <nombre>                muestra canciones de una playlist                                                       │
           │    playlist create <nombre>              crea una playlist                                                                       │
